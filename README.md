# موقع تجربة برنامج إنتاج النسيم

يضم المجلد `dist` موقع تجربة برنامج الإنتاج المخصص لفريق النسيم. يبدأ من `dist/index.html` التي تربط بالحالتين التطبيقيتين والدليل المطبوع. عند الرفع، تُنشر محتويات `dist` معًا على استضافة ملفات ثابتة.

## تنفيذ الخطوات

- اختر «ابدأ التجربة» من الصفحة الرئيسية. تعرض كل مرحلة المطلوب تنفيذه والنتيجة المتوقعة، مع قيم جاهزة كمرجع لإدخال مثال الباب الواحد.
- افتح الدليل المطبوع لتسجيل نتيجة الخطوة وملاحظتك أثناء التطبيق.
- يحفظ المتصفح تقدم التجربة، ويمكن إعادة كل حالة من بدايتها.

## مراجعة الفريق

- **الحالة أ** تبدأ بطلبية باب واحد. ينفّذ الفريق التسجيل والمراجعة الفنية واعتماد المواد وطباعة A4 وتسجيل التصنيع والتوريد.
- **الحالة ب** تبدأ بمسودة من ثلاثة أبواب متطابقة بانتظار مراجعة المواد. يختبر الفريق إيقاف الإصدار، ثم يستكمل طول قص الماسورة ويطابق قائمة القص وملخص المخزن.
- افتح `dist/guide.html` أو استخدم زر «افتح دليل المراجعة» لطباعة الدليل. توجد مساحة لتسجيل نتيجة كل خطوة وملاحظتها.
- مرّر المؤشر على أي حقل في نموذج الإدخال، أو استخدم زر «؟» باللمس أو لوحة المفاتيح، لقراءة معناه. تعرض مراجعة المواد «كيف حُسبت الكمية؟» لشرح عدد قطع المجاري وطولها وإجمالي طول الماسورة.

الطلبيات وأدوار الاختبار بيانات تجريبية داخل المتصفح. يحفظ كل متصفح تقدمه محليًا، ويعيد زر «إعادة ضبط هذه الحالة» الحالة المختارة إلى بدايتها. نموذج الموقع يحاكي دورة البرنامج الحالية وقواعد الكميات التجريبية. يعتمد تشغيل المراجعة على استضافة الملفات فقط، ويستلم صاحب المشروع الملاحظات في الدليل المطبوع.
